# organimo-clone

仿照 [Organimo](https://organimo.com/)（Sea Moss 保健品电商）开发的前端静态项目，仅用于前端学习与技术研究。

## 本地预览

```bash
python -m http.server 8090
```

浏览器打开 <http://127.0.0.1:8090/>

## 内容

- 30 个页面：首页、产品页（seamoss）、博客 news、cart / checkout / my-account、批发 wholesale、政策页等
- WooCommerce 主题构建产物（style / js）、所用插件的前端资源
- 媒体库全量图片（原图及各尺寸裁剪）
